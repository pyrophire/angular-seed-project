# CHANGEME

## Getting Started

Install project dependencies with `npm install`, then start the application with `npm start`.

## Development

The application is an Angular project. Feature routes live in `src/app/app.routes.ts`, and shared components are under `src/app/components/common`.

## Documentation

Add markdown files to this folder and register them in `src/assets/markdown/manifest.json`. The document viewer loads the selected document on demand.
